# Places photography

Upload original photographs for the Photography page here.

Recommended format:

- JPEG or WebP
- 1600–2400 pixels on the long edge
- Descriptive lowercase filenames, for example `nairobi-rainy-street-01.jpg`
- Organize larger collections in city or journey subfolders

After images are uploaded, update `photography.html` to replace the placeholder panels with the selected photographs and captions.
